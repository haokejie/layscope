# LayScope · Chrome／Edge 浏览器扩展

[中文使用说明](../../README.md) · [English guide](../../README.en.md) · [MIT](../../LICENSE)

此目录用于维护浏览器扩展入口、最小权限、共享核心加载、启停和清理。

悬浮入口可通过面板内的“显示悬浮入口”或弹层的“悬浮入口”开关切换。0.4.0 起按站点记忆，刷新和自动加载继续保持；存储契约由[共享核心](../../packages/core/README.md)维护。入口隐藏后通过 Alt+Shift+L 或工具栏弹层的面板开关恢复面板，面板和布局值保持独立。

从 [GitHub Releases](https://github.com/haokejie/layscope/releases) 下载 `layscope-chromium-vX.Y.Z.zip` 并解压，选择直接包含 `manifest.json` 的固定目录；也可运行 `npm run build` 使用 `dist/chromium`。在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 打开开发者模式，使用“加载解压缩的扩展”选择该目录。不要选择 GitHub 自动生成的源码 ZIP。

更新下载包时替换同一安装目录中的文件，并在扩展管理页重新加载；下载包不会自动更新。打包和校验步骤见[中文使用说明](../../README.md#下载发布包)。

LayScope 按独立的新扩展安装。先停用旧工具并刷新已注入的页面，再选择下载包解压目录或本项目 `dist/chromium`，在新扩展里重新设置规则和主机授权；不迁移或删除旧配置。后续更新 LayScope 时保持其自身路径并原位重载。构建目录包含 MIT `LICENSE`。

点击工具栏入口，紧凑弹层显示当前主机、路径及实例状态。“当前页面”中面板、显示布局、悬浮入口是独立开关；未加载时打开面板不会显示布局，打开布局则静默加载并保持面板收起。入口开关在加载后可用，保留站点偏好。“移除”只释放本页实例，不停用自动加载规则。0.8.0 起，同一核心函数通过 `chrome.scripting.executeScript` 在顶层页面的 MAIN 世界执行，以读取页面的 Vue 3 元数据；核心不使用扩展 API。浏览器保护页面不能注入，错误明确显示。

Go/templ 标记与 Vue 3 的识别优先级、自动／仅 DOM 模式、来源状态与存储统一由[共享核心](../../packages/core/README.md#组件识别)维护，弹层和后台不复制识别代码。手动调用按 documentId 固定目标；页面探针只读取 URL 与加载状态，不查询或清理隔离世界的实例。LayScope 只管理自己的 MAIN 实例；其他工具应由其自身入口移除。

“管理页面规则”通过 [`runtime.openOptionsPage`](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-openOptionsPage) 打开／复用独立的 `rules.html` 标签页，弹层不包含规则列表、表单或折叠区。完整列表提供域名／路径搜索、状态筛选、添加、启停、默认布局、重新授权和确认删除。规则管理只保存设置，不向业务页面注入；打开或刷新命中页面时再按规则自动加载。后台只接受本扩展两个管理页面的准确 sender URL，独立管理页可携带 sender.tab，业务页面发送的规则命令仍被拒绝。

基础权限为 `activeTab`、`scripting`、`storage`，没有必需的全站主机权限。自动加载使用可选主机权限，仅在用户添加或启用规则时按主机请求授权；浏览器授权覆盖该协议和主机的全部端口，实际规则仍精确区分端口。权限机制见 [Chrome 官方可选权限文档](https://developer.chrome.com/docs/extensions/reference/api/permissions)。最低支持 Chrome／Edge 106。

## 指定页面自动加载

没有启用的多页规则覆盖当前页面时，打开“此页面自动加载”开关并接受主机授权，即可记住当前精确页面。关闭开关停用这条精确规则，并隐藏默认布局设置；保存的默认值仍可在完整列表调整。

如果启用的路径规则覆盖此页，弹层以“由规则管理”及具体路径规则代替快捷开关，点击进入完整列表；主机权限失效时明确显示“需授权”。即使存在优先级更高的精确规则，关闭它后仍会由路径规则接管，因此这类组合也统一在列表管理。停用精确规则不是禁止加载的排除规则，匹配优先级保持不变。

“默认显示布局”是每条规则的持久偏好，新规则默认关闭。自动加载新实例时按它初始化，保持面板收起、不抢焦点、不选取。独立启用的精确规则可在弹层快捷修改；多页规则及规则组合需到完整列表修改。修改默认值只影响后续新实例，不改变当前实例；当前页面的实时开关不回写规则。

- 精确页面：`http://127.0.0.1:8083/projects`。
- 指定路径及其下级：`http://127.0.0.1:8083/projects/*`；此规则不匹配没有末尾 `/` 的 `/projects`，需要时另加精确规则。
- 同一端口整个站点：`http://127.0.0.1:8083/*`。
- 只允许 HTTP／HTTPS 的具体主机，`*` 仅用于路径；忽略查询参数和 `#` 片段，区分协议、主机、端口及路径大小写。不接受带账号密码、查询参数或片段的规则。最多保存 50 条规则。

规则可停用、重新启用或删除。权限被用户撤销时保留规则，并显示“需授权”及授权入口；确认删除同一协议和主机的最后一条规则会申请撤销该主机的常驻权限。停用或删除规则不强制移除已加载的实例，可用弹层“移除”清理。

自动加载由 MV3 后台监听顶层标签页完成加载和 URL 变化触发，支持整页刷新与单页应用路径切换，不安装驻留于所有页面的内容脚本。非匹配页面不执行注入脚本。后台休眠恢复后，仍通过 `storage.session` 的文档 ID 和路径记录尊重本页的手动关闭／移除；同一文档同一路径不因重复完成事件、查询参数或片段变化而重新打开。整页刷新会创建新文档并可再次加载；已有实例收起时保持收起，完全移除后进入新的命中路径或离开后重新进入命中路径可再次加载。单页应用离开规则路径不会强制移除已有实例。

命中规则由后台与弹层共用 `resolveRule`：启用且匹配的精确页面优先；否则路径非 `*` 字符越多越优先，再比较 `*` 越少越优先，最终按规范化 pattern 固定字典序。顺序不依赖添加时间；优先规则缺主机权限时要求授权，不改用较低优先规则。

设置 version 2 的每条规则必须含 `id`、`pattern`、`enabled`、`defaultLayoutVisible`。仅从 `layscope.autoLoadSettings` 读取严格 v2；v1、未知版本、缺字段或损坏数据均报错且不覆盖，不提供迁移。默认值编辑不注入页面；新增／启用可在缺少实例时静默加载，已有状态保持。

规则保存在此浏览器的 `storage.local`，不上传；本功能属于 Chromium 接入端，不改变 Codex 插件的显式加载方式。

## 更新与排错

修改核心或后台后，仅重建并刷新业务页面还不够：仍运行的 service worker 可能缓存了含旧核心的 auto.js。需要在扩展管理页对现有 LayScope 点击“重新加载”，再关闭并重新打开弹层。弹层同时核对浏览器 manifest.version 和后台实际 coreVersion；即使设置协议都是 v2，旧自动加载核心也会显示“更新扩展”。配置错误不覆盖页面状态；手动页面操作仍可用。

页面“需更新”提供普通尺寸的“更新实例”按钮，一次清理自身 MAIN 世界中过期的 LayScope 实例，再由新核心恢复原面板状态及可读取的布局和入口值；旧入口隐藏值同时保存为站点偏好。其他执行世界实例仍需用其自身 UI 移除。刷新后反复旧版应更新扩展后台，反复更新页面实例不能替代这一步。

检测到旧配置或后台无接收端时，弹层会用“更新扩展”按钮替代不可操作的开关。用户点击后先清理当前页属于本扩展的已知实例，再通过 [`chrome.runtime.reload()`](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-reload) 重新读取本机扩展配置。弹层会关闭，重新打开后再开启自动加载并确认主机授权。更新按钮不会自行授予主机权限，也不会循环重载；其他曾加载检查器的标签页可刷新清理旧实例。

`Could not establish connection. Receiving end does not exist.` 表示弹层没有收到后台接收端。先按上面步骤重新加载扩展；若仍报错，在扩展卡片的“错误”中查看 service worker 启动错误。不要通过刷新业务网页替代扩展重新加载。当前构建会验证后台模块完整导入和事件注册，但浏览器真实安装与运行状态须另行确认。

`npm run dev` 的 `/popup/` 与 `/rules/` 提供实际 HTML／CSS／JS 的交互预览，Chrome API 使用明确的测试替身，不申请浏览器权限；它不代替真实扩展后台验收。预览中的导航在当前页切换，真实扩展通过选项页 API 打开独立标签页。预览脚本不进入交付包。

验收结束或卸载前请在弹层使用“移除”，或刷新页面。浏览器禁用扩展不会自动执行已注入脚本的卸载回调。

Edge 已通过工具操作实际扩展弹层加载、关闭、重开和完全移除，完整核心的拖拽、树悬停和清理已在 Edge 验证。用户随后确认独立版手动验收完成并授权 Kivo 切换；Chrome 安装状态未由工具重复核实。实际验收来源见[当前事项](../../.task/shared-core-adapters/TASK.md)，接入层遵循[模块边界](../../CONVENTIONS.md#模块边界)。

0.2.0 的真实 Edge 后台验收已覆盖静默加载、规则默认值、刷新、精确规则优先、同文档路径切换、手动移除去重及设置恢复，复用已有主机授权，历史证据见[事项记录](../../.task/popup-auto-load/TASK.md)。0.4.0 已在真实 Edge 验证隐藏入口后刷新自动加载仍保持隐藏、面板保持收起；Codex 内置 Browser 已验证同一核心及自动加载函数沿用站点偏好。旧实例更新及旧后台提示另由弹层测试替身验证；Chrome 原生安装入口未单独验收。
