# 共享核心与双端接入

状态：DONE

目标：先验证 Chrome / Edge 扩展与 Codex 内置 Browser 共用核心的加载、关闭、完全清理，再迁移 Kivo 已有检查功能。开发规范见 [CONVENTIONS.md](../../CONVENTIONS.md)。

## 验收

- [x] 同一核心构建到两个接入端，无检查逻辑副本。
- [x] 内置 Browser 实际执行加载、关闭、重开、移除。
- [x] Edge 的 Chromium 扩展实际执行加载、关闭、重开、移除。
- [x] 重复启停与移除后无节点、样式、监听器、观察器、定时回调残留；业务布局不变。
- [x] 双端生命周期验收后迁移层级、选择、悬停、拖拽与折叠。
- [x] 用户确认独立版手动验收完成并授权切换；此前待用户验收的接入项按该确认接收，工具未重复核实 Chrome 安装或插件发现。
- [x] Kivo 删除旧 UI 资源及自动加载／分发入口，仅保留可选名称元数据，并完成运行服务切换。

## 当前事实

2026-10-16：先通过 Edge 真实扩展入口及 Codex Browser 验收共享核心，再迁入既有检查功能。用户随后确认“我已经手动验收完成。开始切换”，据此完成 Kivo 切换。Kivo 的 Document 自动加载、资源分发和三份内嵌 JS／CSS 均已移除；devtools 只提供 dev 构建的名称元数据，现有公共组件调用不变。独立核心一并删除了旧 Kivo 检查器宿主的专用排除分支。

## 交付边界

工具实现、构建及交互由本仓库唯一维护；Kivo 只保留可选名称标记。浏览器扩展和 Codex 插件安装由用户管理，本轮未变更插件安装配置。独立工具的手动验收结论来自用户确认，不替换或补写为工具执行记录。此前浏览器内部管理页的 URL 策略限制未被绕过。
