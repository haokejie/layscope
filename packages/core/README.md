# LayScope 共享核心

此目录是双端共用的唯一 DOM 检查实现。`runtime.js` 管理状态与资源，`recognition.js` 只读识别组件，`view.js` 管理检查数据和界面，`inspector.css` 只用于 Shadow Root。构建生成自包含函数 `layScope(command = "open", options = {})`。

## 标识与存储

LayScope 使用独立命名空间，不保留旧产品别名或迁移路径。

| 范围 | 标识 |
| --- | --- |
| 核心导出／注册表 | `layScope`／`__layScopeV1__` |
| 宿主与布局边界 | `<layscope-inspector>`、`data-layscope-layout`、`data-layscope-boundary` |
| 组件元数据 | `data-layout-component`、`data-kivo-component`、`data-slot` |
| 站点偏好 | `layscope.launcherVisible`、`layscope.detailsVisible`、`layscope.panelWidth`、`layscope.recognitionMode` |
| 扩展消息／存储 | `layscope-rules`、`layscope.autoLoadSettings` v2 |
| 扩展 session | `layscope.autoLoadVisit:<tabId>`、`layscope.autoLoadError:<tabId>` |
| Codex 插件／技能 | `layscope`、`skills/layscope/` |

配置只读写这些键。缺少设置时以空规则和默认站点偏好启动，不读取旧键、不创建存储副本，也不清理其他工具的数据。设置只接受严格 v2，不支持 v1 迁移。两端在顶层页面 MAIN／默认环境运行核心，不接管隔离世界中的旧实例。切换前应关闭旧工具并刷新页面。

## 命令与状态

| 命令 | 行为 |
| --- | --- |
| `load` | 新实例静默加载，面板收起；layoutVisible 默认 false，launcherVisible 默认读取本站点偏好。可显式传这两个布尔选项；launcherVisible 同时保存偏好。已有实例保持现场状态且不重写偏好。 |
| `open` | 显示面板；首次创建时布局与选取均关闭，已有实例的布局值不变。 |
| `close` | 收起面板、结束选取和瞬时预览，保留布局开关值及启动入口。 |
| `toggle` | 只切换面板；与启动入口、Alt+Shift+L 行为相同。 |
| `set-layout` | 必须传 `{layoutVisible: boolean}`；只改变已加载实例的布局，关闭时结束选取。未加载时报错。 |
| `set-launcher` | 必须传 `{launcherVisible: boolean}`；保存本站点入口偏好并改变当前实例入口，不改变面板、布局和选取。未加载时报错。 |
| `destroy` | 完整释放实例、资源、标记与全局入口。 |
| `status` | 只查询；未加载时返回 `{state: "absent"}`。 |

`load` 接受两个可见性选项，`set-layout`／`set-launcher` 只接受对应的必填布尔字段；其他命令不接受选项。非法选项先拒绝再执行。未加载时 `close`、`destroy`、`status` 不创建实例。

已加载状态包括 `version`、`panelOpen`、`layoutVisible`、`launcherVisible`、`picking`、节点数、选择／预览和资源计数。字段 `state: open/closed` 只表示面板展开／收起，不能用它推断布局显示。旧版本仍可查询、移除，其他控制明确要求先移除旧实例。跨执行世界发现其他宿主时拒绝重复挂载，不接管其清理。

`recognition` 状态包含 `mode: auto/dom`、实际识别来源 `sources`（组件标记／Vue 3）和 `vue: available/unavailable/absent/disabled`。检测到 Vue 3 应用但没有可读组件元数据时返回 unavailable，面板明确提示“组件信息不可用”；仅 DOM 模式返回 disabled。面板和布局均关闭时不收集业务信息，sources 只代表最近一次检查。

## 组件识别

默认自动模式。名称优先级为 `data-layout-component`／兼容的 `data-kivo-component` → Vue 3 组件根节点 → `data-slot` → 实际 DOM 名称；两种显式组件标记冲突仍报错。Go/templ 页面沿用已有标记，无需选择后端框架。状态显示实际来源，不根据 HTML 猜测服务端语言。

Vue 3 开发版（或保留开发元数据的构建）读取组件实例的名称、SFC 推断名称及可用源码文件名；无名称时明确显示“匿名 Vue 组件”。组件根节点显示组件名，内部普通 DOM 保留标签名，详情补充“所属组件”。多根节点分别命名，Teleport 继续位于实际挂载位置，不伪造逻辑组件树。不读取／修改 props、响应式状态、Vue DevTools hook 或 Vue 生命周期。内部元数据参考 [Vue 3.5.22 renderer](https://github.com/vuejs/core/blob/v3.5.22/packages/runtime-core/src/renderer.ts#L668)，属于受版本约束的开发信息；真实 runtime 验收版本为 3.5.22。普通生产构建缺少元数据时保留显式标记和 DOM 检查，并提示组件信息不可用。

面板设置的“组件识别”提供自动／仅 DOM，按 origin 保存 `layscope.recognitionMode`（字符串 auto／dom，默认 auto）。仅 DOM 不读取组件标记、slot 或 Vue 信息；“普通 DOM”开关仍负责未标记元素的显示范围。切换模式保留当前选中的实际元素、分支折叠、详情偏好、面板尺寸和布局状态；选中元素在过滤后仍保留。存储失败还原模式并显示错误，损坏的存储值不覆盖。公开命令及参数保持不变。

识别随现有 DOM 刷新执行，覆盖动态挂载／移除及标记变化，不额外轮询或常驻挂钩。只读扫描 Vue 应用已渲染的 VNode，补齐编译器静态根节点缺少 DOM 实例标记的情况；内部普通 DOM 仅在有真实归属元数据时显示所属组件。每次扫描只在局部持有 Vue 引用，界面仅保存名称与归属字符串；关闭检查／销毁沿用统一资源清理。

## 独立控制

面板内顶部“显示布局”控制当前实例的边界、名称浮层与高亮，手动修改不回写自动加载规则。布局关闭时仍可使用树、尺寸和详情；选取按钮不可用。选取只能由用户明确开启，要求面板与布局同时开启。

布局开启且面板收起时，业务变化继续刷新边界、被动悬停可显示名称，业务点击正常。收起面板结束选取及瞬时预览。任何加载或展开命令都不会自动选取或抢焦点。

鼠标离开页面、窗口失焦或文档隐藏时，清除页面及层级树的瞬时预览。已有固定选择和详情保持，高亮恢复到固定元素；没有固定选择时隐藏高亮与名称浮层。页面内部移动不会提前清除预览，鼠标重新进入后按当前位置更新。

面板右上角“面板设置”中的“显示悬浮入口”和扩展弹层的“悬浮入口”开关共用此站点（精确 origin，含端口）的持久偏好，键为 localStorage 的 `layscope.launcherVisible`，仅保存字符串 true／false。刷新、自动加载及同站点的后续新实例均读取它；未设置时显示，不回写自动加载规则，也不强制改变其他已运行实例。关闭／移除不会删除偏好，重新勾选才恢复显示。隐藏后 Alt+Shift+L、核心 open／toggle 或扩展的面板开关仍可打开面板。

## 面板操作

常用工具栏保持单行：选取、清除、布局显示和普通 DOM。快捷键说明、入口偏好和完全移除放在右上角“面板设置”，设置以浮层展示，不改变内容区尺寸；点击外部或按 Esc 收起。

默认开启“自动收起祖先”，可在面板设置中切换，开关只作用于当前实例。选中深层节点或展开触及当前缩进范围的分支时，将远处祖先收进层级栏的“⋯ N级”入口，保留最近 3–5 层上下文；面板较窄时保留更少祖先。悬浮预览不改变范围。层级栏“显示上一层”、祖先路径和“返回完整树”只改变显示范围，保留当前选择、详情偏好和所有分支的折叠状态；选择元素仍按原逻辑展开其祖先。完整树恢复后，下一次深层选择／展开才继续自动跟随。全部展开／全部折叠同时返回完整树，其他行为沿用原约定。

自动收起祖先不改写折叠集合。`visibleNodes` 仍表示全树按折叠状态可见的节点数；界面计数表示当前显示范围中的节点数，提示同时说明全树计数。动态 DOM 替换使当前视图根失效时返回完整树，不保留已脱离文档的引用。

树连接线以统一的行高、缩进和控件宽度定位：子分支竖线接到父级展开控件中心，最后一个兄弟节点在本行中心收尾，叶节点横线在箭头预留位中央收尾，名称前保留空白。展开箭头使用固定尺寸的 SVG，在行内居中，旋转不受字体基线影响。收起祖先后的新视图根不显示来自隐藏祖先的连接线。

主面板左右边缘可拖动调宽，也支持方向键微调（Shift 加速）和双击恢复 350px。首选宽度范围为 320–640px，保存在当前 origin 的 localStorage 键 `layscope.panelWidth`，使用整数字符串；默认 350。拖动结束后保存，取消或失去指针捕获恢复原宽度，保存失败明确报错并回滚。拖动时保持另一侧边缘固定，达到视口边缘即停止。窄视口临时限制显示宽度，不覆盖首选值；窗口恢复后沿用原宽度。宽度与入口、面板开关、布局、选择、折叠和详情偏好独立，刷新／静默加载读取同一值。宽度调整后详情继续按既有规则定位和换边。

层级列表常驻；点击节点或选取页面元素后，在主面板旁显示详情并同步更新，鼠标悬浮只预览高亮。详情按元素名称、尺寸、布局与间距、祖先路径分组，独立滚动；路径可点击定位祖先。旧的层级／详情切换页签已移除。

详情优先放在右侧，右侧不足时放在左侧；两侧都不足时覆盖展示，始终限制在视口内并随主面板移动。详情显隐不改变层级列表的尺寸与滚动位置；点击新节点仍按既有逻辑定位。主面板设置或已收起的祖先路径打开时暂时隐藏详情，收起后恢复，不写入显隐偏好。

详情关闭按钮和层级栏的“详情”按钮共用当前 origin 的 localStorage 键 `layscope.detailsVisible`（字符串 true／false），默认 true。主动收起会记住 false，后续选择、刷新、重新加载不强制打开；点击“详情”恢复 true。清除选择、收起主面板或销毁只隐藏详情、不删除偏好；主面板重新展开后，选中元素才按偏好展示。详情内按 Esc 收起；选取模式仍优先由 Esc 结束选取，不拦截业务页面的 Esc。

入口、详情与宽度共用核心的类型校验及偏好存储实现。读取失败或值损坏时明确报错，不覆盖原值；保存失败时保持当前显隐或已保存宽度并显示错误，入口开关还原勾选。两端不另建偏好存储或内存 fallback，核心命令与参数保持不变。

组件名与 slot／DOM 识别、层级折叠与辅助线、悬停、固定／清除选择、拖拽移动、视口约束和内容替换刷新沿用同一实现。识别范围见[项目说明](../../README.md#组件识别)。

## 资源所有权

| scope | 存活条件与资源 |
| --- | --- |
| lifetime | 实例存在：静态控件、启动入口、移动与调宽拖拽、快捷键、pagehide 和宿主移除检测。 |
| inspection | 面板或布局至少一个开启：业务 DOM 引用、MutationObserver、ResizeObserver、刷新帧。 |
| layout | 布局开启：文档样式与标记、名称／高亮、页面指针及滚动监听。 |
| panel | 面板展开：动态树与祖先路径事件；收起后清空树节点。 |

两者都关闭时释放业务引用、观察与待执行检查任务，仅保留最小启动资源。destroy、导航、外部移除宿主、初始化／开启失败均执行完整清理。所有监听器、观察器、帧、定时器和自定义清理通过 runtime scope 注册；动态列表使用委托，不累积节点监听器。

普通业务子节点替换会刷新检查数据并保持现场状态；整体替换 body 并移除宿主（例如 Kivo 的 htmx 历史恢复）会完整销毁实例。自动加载由文档／路径事件触发，不持续监视并重新挂载被移除的宿主。

静态 UI 由 DOM API 创建，样式使用 CSSStyleSheet，不使用 innerHTML／eval 或自建 Trusted Types 策略，不改变业务元素尺寸。构建的双端核心逐字节一致，版本唯一来源为根 package.json。
